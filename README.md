# OverTheWire Bandit – Write-Ups

## About This Repository
This repository serves as a personal knowledge base documenting my progress through the **OverTheWire Bandit** wargame.

It focuses on hands-on Linux usage, practical command-line problem solving, and understanding how core security concepts work in real environments.

Each write-up captures the approach, commands used, and lessons learned while solving the challenges, helping reinforce system-level and security fundamentals.

This project also acts as a growing reference and learning portfolio for my journey into cybersecurity and ethical hacking.

---

##  Learning Objectives
- Build a strong foundation in Linux operating system concepts  
- Improve command-line efficiency and shell usage  
- Understand file permissions, ownership, and access control  
- Learn SSH-based remote access and authentication  
- Develop logical thinking for solving security challenges  
- Maintain a documented learning portfolio for cybersecurity roles  

---

##  Topics & Skills Covered
- Linux file system navigation  
- Common Linux commands (`ls`, `cat`, `find`, `grep`, `strings`, `xxd`, etc.)  
- File permissions and ownership models  
- Hidden files and directories  
- SSH connections and key-based authentication  
- File compression and encoding techniques  
- Environment variables and shell behavior  
- Process handling and restricted shells  
- Basic networking and service interaction  

---

##  Write-Up Format
Each level write-up includes:
- The goal of the level  
- Commands used to solve the challenge  
- Step-by-step explanation of the approach  
- Final result or solution

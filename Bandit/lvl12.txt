Bandit Level 12

Goal:
The password for the next level is stored in the file data.txt, which is a hexdump of a file that has been repeatedly compressed.

Steps:

ssh bandit12@bandit.labs.overthewire.org -p 2220

mktemp -d
cd /tmp/tmp.XXXXX

cp ~/data.txt .

xxd -r data.txt > data
file data

mv data data.gz
gunzip data.gz
file data

mv data data.bz2
bunzip2 data.bz2
file data

mv data data.gz
gunzip data.gz
file data

mv data data.tar
tar -xf data.tar
ls

file data5.bin
mv data5.bin data5.tar
tar -xf data5.tar
ls

file data6.bin
mv data6.bin data6.bz2
bunzip2 data6.bz2
file data6.bz2.out

mv data6.bz2.out data7.tar
tar -xf data7.tar
ls

file data8.bin
mv data8.bin data8.gz
gunzip data8.gz

file data8
cat data8


Result:
Password for the next level was obtained successfully.

Learning:
Learned how to reverse a hexdump using xxd, identify file types using file, and repeatedly extract compressed files (gzip, bzip2, tar) until readable text is obtained.
